# FSRE Sync

FSRE Sync is a university timetable tracking and notification system that started as a personal experiment and evolved into a multi-component project.

## Active repositories

- **Backend** — [`fsre-sync-backend`](https://github.com/FSRE-Sync/fsre-sync-backend)  
  Timetable and subscription backend (TypeScript/Bun/SQLite), with Firebase Cloud Messaging integration for class and news notifications.

- **Web** — [`fsre-sync-frontend`](https://github.com/FSRE-Sync/fsre-sync-frontend)  
  React + Tailwind CSS web client for viewing timetables.

## Stack

TypeScript, Bun, SQLite, Firebase, React, Tailwind CSS, Docker.
